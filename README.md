# Kunst- und Kreativwettbewerbe Kl. 5–10

Inoffizielle Übersicht aktueller Kunst- und Kreativwettbewerbe für Schülerinnen und Schüler der Klassen 5–10 (Kassel, Hessen, Deutschland, Europa).

- Seite: `index.html` (eine Datei, Daten im Array `const D=[...]`)
- Countdowns, Heute-Linie und abgelaufene Fristen berechnet die Seite beim Öffnen selbst.
- Neue Wettbewerbe und Aktualisierungen ergänzt ein monatlicher Claude-Auftrag.

Keine personenbezogenen Daten. Angaben ohne Gewähr – vor der Teilnahme die offizielle Ausschreibung prüfen.
